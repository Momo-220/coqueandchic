📸 Images & Logo

🎨 Logo de la boutique

Le logo apparaît dans le header de toutes les pages. Format recommandé : PNG avec fond transparent, 200×80px minimum.

🖼️ Images des produits

Uploadez les images de vos produits ici, puis associez-les dans la page Produits.

Aucune image uploadée. Allez sur Produits pour en ajouter.

ℹ️ Comment ça marche ?

  • Logo : uploadé une seule fois, apparaît partout
  • Images produits : uploadées depuis la fiche d'ajout/modification de produit
  • Stockage : localStorage de votre navigateur (max ~5 MB total)
  • Format : JPEG compressé automatiquement pour économiser l'espace
  • Reset : pour vider toutes les images, videz le cache du navigateur
